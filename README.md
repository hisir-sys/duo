# DuoAI
pip install -r requirements.txt
python main.py
Sign in with each provider's API key from the top bar (different accounts are fine). Sign out removes the saved key.
Memory lives in ~/.duoai/memory.md and syncs live with the right-hand panel; edit it in any editor.
Single-file installer (optional): pip install pyinstaller, then: pyinstaller --noconsole --onefile main.py
